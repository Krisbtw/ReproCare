## 1. Classification Legend

Every subsystem and work item across Workstreams 1–9 is classified into one of six honest states:
1. **Already implemented and verified** — Present in the codebase and verified by automated tests.
2. **Implemented and verified in this completion cycle** — Completed or hardened during Final Project Completion and verified by automated tests.
3. **Implemented but unverified on real clinical data** — Software pipeline is verified on synthetic/phantom test cases, but awaits real patient/UMD data.
4. **Blocked by unavailable data, credentials or infrastructure** — Code and CLI/API harnesses are ready, but execution requires external dataset download, production secrets, or cloud infrastructure.
5. **Requires external clinical, ethical or regulatory review** — Technical controls and documentation are in place, but formal sign-off requires an Institutional Ethics Committee (IEC), licensed clinicians, legal counsel, or CDSCO.
